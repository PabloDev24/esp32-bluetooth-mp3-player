# ESP32 Bluetooth MP3 Player

Firmware para ESP32 que implementa un reproductor MP3 controlado por Bluetooth Serial.

## Funcionalidad

- Control de reproducción vía comandos Bluetooth (play/pause/stop/avanzar, volumen)
- Reproducción de audio con módulo DFPlayer Mini
- Pantalla de estado en LCD I2C

## Stack

- Arduino (C++) para ESP32
- Bluetooth Serial, DFPlayer Mini, LCD I2C
